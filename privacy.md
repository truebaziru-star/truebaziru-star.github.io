# Privacy Policy

My Clone Rclone is a private personal utility.

The application accesses Google Drive data only to copy, move, list, and delete files as requested by the account owner.

Google user data is not sold, rented, or shared with third parties.

OAuth authorization credentials are used only to allow the application to access Google Drive accounts authorized by their owners.

The application is used only by its owner and a limited number of personally known accounts.

This application uses Google API Services in accordance with the Google API Services User Data Policy.
